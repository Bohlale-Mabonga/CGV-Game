# CGV Game

Welcome to the documentation for our **3D browser-based game**, developed as a group project for **Computer Graphics and Visualisation**.

## About the Project

Our project is an interactive 3D game developed for the web using **Three.js** and modern web technologies. The game consists of three distinct levels, each designed to demonstrate concepts in computer graphics, 3D scene construction, interaction, lighting, and gameplay.

This documentation describes the design, development, implementation, testing, and deployment of the project.

## Technologies

The project makes use of technologies including:

* **Three.js** — 3D graphics and rendering
* **JavaScript** — Game logic and interaction
* **HTML5** — Application structure
* **CSS3** — Interface styling
* **WebGL** — Hardware-accelerated graphics through Three.js
* **Git & GitHub** — Version control and collaboration

## Project Structure

The project is organised into three main areas:

1. **Game Application** — The playable 3D game.
2. **Documentation** — Technical and project documentation.
3. **Deployment** — Production files used to host and submit the project.
