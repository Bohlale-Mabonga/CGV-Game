# Controls

| Input | Action |
|---|---|
| Click the game window | Locks the mouse pointer (needed for mouse look) |
| W A S D / arrow keys | Move |
| Mouse | Look around |
| Space | Jump. In Level 3, press it again in mid-air for the thruster double-jump |
| Shift | Sprint (uses stamina) |
| C / Ctrl | Crouch (to get under steam leaks) |
| E / left click | Interact. Some objects need you to hold it (junctions, pylons, the core seal) |
| F | Flashlight on/off (the battery drains while on and recharges while off) |
| Q / right click | Scanner ping: shows nearby items through walls for 5 s (8 s cooldown) |
| V / mouse wheel | Switch first/third-person view; zoom the third-person camera |
| M / Tab | Change the minimap size (small → large → hidden) |
| H | Hint (press again for more detail) |
| Esc / P | Pause menu |

The keypad (Level 1) and the routing grid (Level 2) are mouse-driven. The keypad also accepts number keys and Enter.

Pickups (batteries, repair kits) are collected just by touching them.

## Options menu

The options menu covers:
- **Audio:** master, music and effects volume; ARIA's voice on/off; subtitles.
- **View:** mouse sensitivity, invert Y, field of view, camera shake and head bob.
- **Game:** difficulty, graphics quality, an FPS counter.

All settings are saved in the browser.
