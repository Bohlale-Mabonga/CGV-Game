# Controls

| Input | Action |
|---|---|
| Click the game window | Locks the mouse pointer (needed for mouse look) |
| W A S D / arrow keys | Move |
| Mouse | Look around |
| Space | Jump. In Level 3, press it again in mid-air for the thruster double-jump |
| Shift | Sprint (uses stamina) |
| C / Ctrl | Crouch (to get under steam leaks) |
| E / left click | Interact. Some objects need you to hold it (junctions, pylons, the core seal) |
| F | Flashlight on/off (the battery drains while on and recharges while off) |
| V / mouse wheel | Switch first/third-person view; zoom the third-person camera |
| M / Tab | Change the minimap size (small → large → hidden) |
| H | Hint (press again for more detail) |
| Esc / P | Pause menu |

The keypad (Level 1), and the load diagnostic and routing grid (Level 2), are mouse-driven. The keypad also accepts number keys and Enter, and the diagnostic's pads also respond to keys 1–4.

Pickups (batteries, repair kits) are collected just by touching them.

## Menus

- **How to play:** a short guide to the goal, the three levels, staying alive, and tips. It's on the main menu and the pause menu.
- **Options:** master, music and effects volume; ARIA's voice on/off; subtitles; difficulty. Settings are saved in the browser.
- **Controls:** the key list above.

To keep things simple, mouse sensitivity, field of view, camera effects and graphics quality aren't player options. They use sensible defaults, and the game adjusts its resolution automatically to keep the frame rate up.
