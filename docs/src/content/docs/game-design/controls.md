# Controls

| Input | Action |
|---|---|
| Click game window | Locks the mouse pointer (required before movement/look responds) |
| W / A / S / D | Move forward / left / back / right |
| Mouse movement | Look around (the flashlight is attached to the camera, so it follows your view) |
| E | Interact with the nearest interactable object (door, power junction) |
| F | Toggle the flashlight on/off |
| Esc | Releases the mouse pointer |

Keycards do not require a button, walking within range collects them automatically.
